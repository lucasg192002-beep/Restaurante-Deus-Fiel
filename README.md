# Restaurante Deus é Fiel

Site oficial do **Restaurante Deus é Fiel**, em Caetés, Pernambuco.

## Sobre este projeto

O site inteiro (Início, Sobre, Delícias, Cardápio, Depoimentos, Localização e Dúvidas) está em um **único arquivo**: `index.html`.

- Não depende de nenhuma pasta externa — CSS, JavaScript e todas as imagens estão embutidos no próprio arquivo.
- Funciona offline, com clique duplo, em qualquer computador ou celular.
- A navegação entre as seções acontece por JavaScript (sem recarregar a página).

## Como usar

Basta abrir o arquivo `index.html` em qualquer navegador (Chrome, Safari, Edge, etc.).

## Como publicar como site online (GitHub Pages)

Este repositório já está pronto para virar um site de verdade e gratuito com o GitHub Pages:

1. No repositório, vá em **Settings** → **Pages**.
2. Em "Source", escolha a branch **main** e a pasta **/(root)**.
3. Clique em **Save**.
4. Em alguns minutos, o GitHub mostrará o link do site (algo como `https://lucasg192002-beep.github.io/Restaurante-Deus-Fiel/`).

## Atualizações futuras

Qualquer alteração de texto, foto ou preço pode ser feita direto no `index.html` e enviada novamente para este repositório.
